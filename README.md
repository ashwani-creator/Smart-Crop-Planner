# Smart-Crop-Planner
This project is a Machine Learning-based Crop Prediction System that predicts the most suitable crop based on soil nutrients and environmental conditions.  The model uses input features such as Nitrogen, Phosphorus, Potassium, Temperature, Humidity, pH, and Rainfall to predict a suitable crop.
*Features:
.Crop prediction using Machine Learning
.Uses soil and environmental parameters
.Data analysis and visualization
.Trained machine learning model
.Predicts crop categories based on input values
*Technologies Used
.Python
.Jupyter Notebook:
.Pandas
.NumPy
.Matplotlib
.Scikit-learn
*Machine Learning Algorithm:
.Support Vector Classifier (SVC)
*Input Features:
.Nitrogen (N)
.Phosphorus (P)
.Potassium (K)
.Temperature
.Humidity
.pH
.Rainfall
